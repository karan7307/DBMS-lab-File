## 👨‍💻 About This Repository

Welcome to my **Database Management System (DBMS) Lab Repository**!

This repository contains my DBMS laboratory experiments, SQL queries, practical implementations, and related documentation.

The main objective of this repository is to understand database concepts through practical implementation using SQL and MySQL.

## 🎯 Objectives

- Understand database concepts and relational database management.
- Practice SQL commands and queries.
- Implement different types of SQL joins and subqueries.
- Learn database normalization techniques.
- Understand transactions and concurrency control.
- Implement stored procedures and triggers.
- Explore indexing and query optimization.

## 🚀 Getting Started

Follow these steps to run the SQL experiments on your local machine.

### Prerequisites

- MySQL Server 8.0 or later
- MySQL Workbench or MySQL Command Line Client

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/karan7307/DBMS-lab-File.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DBMS-lab-File
   ```

3. Open the required `.md` file and copy the SQL queries.

4. Execute the queries in MySQL Workbench or your preferred MySQL client.

5. Check the output and verify the results.
